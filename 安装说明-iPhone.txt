这个版本是「PWA（渐进式 Web 应用）」：界面、数据和安卓版一致
（首页/行程/票券/出门检查/离线 PDF 与图片凭证），iPhone 的
Safari「添加到主屏幕」后全屏运行、长得像原生 App、离线可用。

注意：本 App 不是 App Store 应用。要想完整离线 + 全屏体验，需要
先把它放到一个 HTTPS 网址上（免费），再把网址装到主屏幕。

──────────────────────────────
【方法一：GitHub Pages 免费托管（推荐，完整离线）】
──────────────────────────────
1. 打开 github.com 注册/登录账号（免费，约 2 分钟）；
2. 右上角 + 号 → New repository → 仓库名随便填（如
   italy-trip），勾选 Public → Create repository；
3. 点「uploading an existing file」→ 把本文件夹里除 .txt 外
   的所有文件（index.html、app.css、app.js、trip.js、sw.js、
   manifest.webmanifest、trip.json、icons 文件夹、tickets 文件夹）
   拖进去 → Commit changes；
4. 仓库 Settings → Pages → Source 选 Deploy from a branch →
   Branch 选 main → Save；
5. 等 1 分钟，得到网址: https://用户名.github.io/仓库名/
6. iPhone 用 Safari 打开这个网址 → 点分享按钮 → 「添加到主屏幕」
   → 添加。以后从主屏幕图标打开，同机场无网也能用（首次在线
   打开过一次后完全离线）。

──────────────────────────────
【方法二：Netlify Drop（更快，同样免费 HTTPS）】
──────────────────────────────
1. 电脑浏览器打开 https://app.netlify.com/drop
2. 把本文件夹整体拖进页面 → 发布
3. 得到 https://xxx.netlify.app 网址 → iPhone Safari 打开 →
   分享 → 添加到主屏幕（步骤同方法一第 6 步）

──────────────────────────────
【方法三：仅临时预览（不能离线，不建议旅行用）】
──────────────────────────────
电脑解压本文件夹后运行：python -m http.server 8000
iPhone 与电脑连同一 WiFi，Safari 打开 http://电脑IP:8000

──────────────────────────────
功能说明（与安卓版完全一致）
──────────────────────────────
· 首页：倒计时/进度、路线总览、搜索、全部行程日
· 行程：Day 1–11 左右滑动翻页，携带/时间线点按打勾自动保存
· 票券：7 份票券 + 酒庄图片凭证，点开即看（PDF 支持单指翻页、
  双指缩放）
· 出门：30 项必需品分组打勾、全部确认才显示「可以出门啦」、
  可增删物品、重置默认清单
· 自动适配 iOS 深色模式
